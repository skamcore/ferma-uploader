Privacy policy

Ferma uploader · last updated: 14 October 2026

Ferma uploader is a private tool used only by its developer to manage the developer's own YouTube channels.

Data accessed

When the developer signs in with Google, the tool receives an OAuth token that allows it to upload videos to the signed-in YouTube channel and to read basic information about that channel's videos (YouTube API Services).

How data is used

  • The token is used only to upload the developer's own videos and to read view statistics of those videos.
  • Tokens and statistics are stored only on the developer's own computer/server and are never shared, sold or transferred to third parties.
  • No personal data of other users is collected, stored or processed.

YouTube and Google

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page. Stored tokens are deleted on request.
